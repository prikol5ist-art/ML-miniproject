# Демо Fashion-MNIST

Відкрийте `demo.html` у браузері. Сторінка працює без сервера та інтернету.

1. Оберіть зображення в таблиці або клас у списку.
2. Натисніть «Показати відповідь моделі», щоб побачити прогноз, правильну мітку та оцінки ймовірності для всіх класів.
3. Оберіть «Помилки моделі», щоб показати приклади неправильних відповідей.

Передбачення для 120 зображень із тестової вибірки обчислені заздалегідь: це модель RBF-SVC із 50 компонентами PCA, навчена на стратифікованій підвибірці з 12 000 тренувальних зображень (`random_state=42`). Для цього демо та сама конфігурація навчена з `probability=True`, щоб SVC оцінила ймовірності через внутрішнє калібрування. Оригінальний експеримент використовує стандартне `probability=False`. Найвища оцінка ймовірності іноді може відрізнятися від класу, повернутого `predict`. Сам файл HTML не запускає модель та не приймає довільні зображення.

Для відтворення демо встановіть залежності проєкту та Pillow, потім запустіть з кореня репозиторію:

```bash
python demo/generate.py
```

За потреби код завантажить Fashion-MNIST через наявні функції проєкту.
